# LEER PRIMERO — Fase 29 V2

Para instalar esta versión desde cero usa, en este orden:

1. `README_INTEGRACION_FASE29_V2.md`
2. `GUIA_PUESTA_EN_MARCHA_FASE29_V2.md`
3. `PRUEBAS_ACEPTACION_FASE29_V2.md`
4. `VALIDACION_INTEGRACION_FASE29_V2.md`

Para un Supabase nuevo, el orden SQL es:

```text
1. base-de-datos/esquema.sql
2. base-de-datos/funciones.sql
3. base-de-datos/permisos.sql
4. base-de-datos/FASE29_01_COMPATIBILIDAD.sql
5. base-de-datos/FASE29_02_INTEGRACION.sql
6. base-de-datos/FASE29_03_DATOS_INICIALES.sql
7. base-de-datos/FASE29_99_VERIFICACION.sql   (solo comprobación)
```

No uses los scripts de migración/actualización sobre una base recién creada.

Para ejecutar localmente, abre la carpeta que contiene `index.html` o ejecuta `INICIAR_LOCAL.bat`. No muevas solo `index.html` fuera de su estructura.
